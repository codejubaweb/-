## 2026-02-20 - Defense in Depth for Single-Page Static Applications (XSS & Clickjacking)
**Vulnerability:** High potential for clickjacking and Cross-Site Scripting (XSS) due to lack of response security headers on static hosts or client-side assets.
**Learning:** For purely static applications (Vite + React single-page apps) with no backend or API gateway, standard HTTP response headers cannot be set from the client side code. Injecting CSP meta tags and inline frame-busting scripts during production compilation directly into `index.html` provides the necessary defense in depth without relying on host-level header configuration.
**Prevention:** Implement automated HTML injection plugins during the Vite build process to enforce restrictive Content Security Policies (restricting script-src/img-src/style-src/connect-src) and embed frame-busting JavaScript logic. Note that `frame-ancestors` is ignored in `<meta>` CSP tags per W3C standards, so clickjacking protection on pure client-side static apps must be handled via frame-busting scripts or host-level headers.
