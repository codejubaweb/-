## 2026-02-20 - Content Security Policy for Single-Page Application with Google APIs
**Vulnerability:** Missing Content-Security-Policy (CSP) meta tag exposed the frontend single-page portfolio application to potential Cross-Site Scripting (XSS), malicious script injections, and untrusted cross-origin network exfiltration.
**Learning:** The application renders external imagery hosted on Google infrastructure (`https://lh3.googleusercontent.com`), relies on Google Fonts (`https://fonts.googleapis.com` and `https://fonts.gstatic.com`), and integrates `@google/genai` which makes network requests to `https://generativelanguage.googleapis.com` and `https://*.googleapis.com`. A generic CSP like `default-src 'self'` would break external fonts, image rendering, and GenAI API communications.
**Prevention:** Always scope CSP directives to allow necessary trusted endpoints (`font-src`, `img-src`, and `connect-src` specifically configured for Google services) while locking down default execution to `default-src 'self'`.
